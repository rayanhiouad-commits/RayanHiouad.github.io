Veille Technologique

☁️ Le Cloud Computing

Définition :

Le cloud computing est l'utilisation de serveurs distants via Internet. Le stockage, le traitement des données et les applications sont externalisés. L'accès se fait principalement via un navigateur web.

Pourquoi utiliser le cloud ?

Forte adoption par les entreprises et développement du e-commerce. La question centrale reste la sécurité et la continuité de service.

Avantages :

  • Réduction des coûts : pas de matériel à acheter.
  • Flexibilité et évolutivité : ressources ajustables selon les besoins.
  • Accessibilité : accès aux données partout.
  • Haute disponibilité : 98 à 99,99%.
  • Sauvegarde des données.
  • Sécurité professionnelle : audits, mises à jour, normes.

Sécurité dans le cloud :

  • Chiffrement des données.
  • Intégrité : protection contre les modifications non autorisées.
  • Localisation des données : data centers multiples.
  • Confidentialité : protection des données sensibles (bancaires, personnelles).

Inconvénients :

  • Risques de sécurité (confidentialité, données parfois à l'étranger).
  • Dépendance à Internet.
  • Performances variables des applications.
  • Coûts cachés (transferts de données).
  • Dépendance au fournisseur (difficile de changer de prestataire).

Types de services Cloud :

  • IaaS : Infrastructure (serveurs, stockage, réseau).
  • PaaS : Infrastructure + environnement de développement.
  • SaaS : Logiciels prêts à l'emploi accessibles en ligne.

Exemples d'outils :

  • Dropbox : simple, stockage gratuit limité.
  • Google Drive : intégré aux services Google, facile d'utilisation.
  • MEGA : très grand stockage gratuit, sécurité renforcée.
  • ASP Serveur : hébergement français, haute disponibilité, écologique.

Comparaison de solutions professionnelles :

Office 365 (Microsoft) : Basé sur Word, Excel, Outlook, OneDrive, etc. Adapté aux entreprises voulant garder leurs outils habituels.

Google Apps for Work : 100% en ligne (Gmail, Drive, Docs). Forte collaboration en temps réel, mobilité, haute disponibilité, sécurité certifiée.

Conclusion :

Le cloud est bénéfique pour les PME s'il est bien choisi. Il faut analyser les besoins (stockage, collaboration, mobilité, coûts, sécurité).

Office 365 assure la continuité des outils existants, tandis que Google Apps favorise la collaboration et l'innovation. L'accompagnement au changement est primordial.
